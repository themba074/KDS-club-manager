# UI mockups

These 19 supplied PNGs are visual references for future KDS Club Manager UI
work. They show useful patterns for visual hierarchy, dense data views,
navigation, empty space, status treatment, and the light and dark design
directions.

They are not product specifications. Several screens show capabilities that
are outside the delivered #0–#21 scope, including investments, payouts,
reconciliation, settings configuration, generated-report history, member
statements, and folders. Do not add or imply those capabilities without a
separate product decision.
